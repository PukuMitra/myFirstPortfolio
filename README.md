**My First Portfolio** is a personal portfolio website created to introduce myself, showcase my technical interests, and present my web development journey.

## 🚀 Run the Project Locally

Follow these steps to run the project on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/pukumitra/myFirstPortfolio.git
```

### 2. Navigate to the project directory

```bash
cd myFirstPortfolio
```

### 3. Open the website

Open `index.html` in your preferred web browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension for local development.
